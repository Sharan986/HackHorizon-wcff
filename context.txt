Design a modern mobile and web UI for a healthcare platform called "MedChain" that predicts occupational health risks for industrial workers.

STYLE:

* Clean, minimal, premium
* Soft depth using layered cards (not flat UI)
* Use subtle gradients (light purple, soft green, white)
* Rounded corners (16px–24px radius)
* Soft shadows (blurred, low opacity, floating feel)
* Slight glassmorphism on top sections (frosted effect with blur)
* Avoid harsh borders; use elevation instead

COLOR SYSTEM:

* Primary: Soft green (#7ED957 or similar)
* Secondary: Light purple gradient
* Background: Off-white / very light grey
* Status colors:

  * Low risk → green
  * Medium → amber
  * High → red (soft, not aggressive)

TYPOGRAPHY:

* Large bold headings for main questions
* Medium weight for labels
* Light for secondary info
* Plenty of spacing (breathing room is important)

---

SCREENS TO DESIGN:

1. WORKER HOME DASHBOARD

* Greeting at top ("How are you feeling today?")
* Profile avatar + notification icon
* Main card (floating):

  * Risk summary (3 scores: lung, hearing, toxicity)
  * Use circular progress indicators or bars
* Below:

  * "Upload Report" button (primary CTA)
  * Previous reports list (card-based)

---

2. REPORT ANALYSIS SCREEN

* Show uploaded report preview
* “Analyzing…” animation (subtle loader)
* After processing:

  * Extracted values in clean grid (FEV1, etc.)
  * Highlight abnormal values with soft color badges

---

3. RISK RESULT SCREEN (MOST IMPORTANT)

* Large central card:

  * “Your Risk Score”
  * Numeric score + label (High/Moderate/Low)
* Below:

  * Explanation section:

    * Bullet points explaining WHY
* Bottom:

  * Recommendations (card list with icons)

---

4. DOCTOR VIEW

* Patient card at top
* Highlight abnormal metrics
* Risk indicators (more detailed than worker view)
* Action suggestions (tests, follow-ups)

---

5. EMPLOYER DASHBOARD

* Overview cards:

  * Total workers
  * High-risk count
* Heatmap-style grid:

  * Zones colored by risk level
* Insights section:

  * “Dust exposure high in Zone A”

---

INTERACTION DESIGN:

* Smooth transitions between screens
* Cards should slightly scale on tap
* Floating elements should feel layered (z-axis depth)
* Use micro-interactions:

  * Button press ripple
  * Soft loading shimmer

---

LAYOUT PRINCIPLES:

* Use card stacking to create depth
* Maintain consistent padding (16–24px)
* Avoid clutter; each screen should have ONE focus

---

OUTPUT:

* Provide UI component structure
* Include spacing, hierarchy, and visual grouping
* Focus on clarity, depth, and modern feel
